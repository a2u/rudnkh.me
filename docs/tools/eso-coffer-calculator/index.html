ESO Coffer Calculator

A companion to ESO Coffer Math. Pick the Pledge Master, fill in how many pieces each set has and how many you still don’t own. The table shows the probability that a single curated of that set hands you a new piece; the panel underneath compares the best curated bet against 8 mystery pulls (same 8-key cost).

Edits persist locally in your browser per vendor, so you can come back later and pick up where you left off.
